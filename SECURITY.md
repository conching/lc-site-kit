# Security policy

Please report suspected vulnerabilities privately through GitHub's
**Security > Report a vulnerability** flow for the affected repository:

- `conching/lc-site-kit` for kit-level packaging, setup, or workflow issues.
- `conching/lc-bricks-mcp` for MCP, authentication, Bricks, media, or updater issues.
- `conching/lc-core` for import, content filtering, or normalization issues.

Do not open a public issue with exploit details or sensitive site information.
Include the affected version, reproduction steps, expected impact, and any logs
with credentials, application passwords, tokens, and personal data removed.

The currently supported release line is the latest tagged release of each
repository. Security fixes may be released without backporting to older lines.
